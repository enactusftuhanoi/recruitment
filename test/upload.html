Test script nộp file

Trang độc lập để test riêng đoạn script upload file lên Google Drive qua Apps Script (dùng đúng URL & secret hiện có trong teamwork.html) — không cần đăng nhập, không đụng vào Firestore, không tạo bài nộp thật.

File test này chỉ gọi Apps Script để upload lên Drive — nó KHÔNG ghi gì vào Firestore, nên team/bài nộp trong app chính không bị ảnh hưởng. Nhưng file bạn chọn sẽ thật sự được tải lên Google Drive (vào đúng thư mục mà script cấu hình), nên nhớ dọn/xoá file test sau khi xong nếu cần.

Cấu hình script

Copy sẵn từ teamwork.html. Nếu bạn deploy lại Apps Script (URL mới), dán URL mới vào đây để test.
